🚀 Choose Your Adventure

Review the three paths below and pick the one that excites you the most. Use the starter prompt to kick off your app, and then follow the prompt-steering goals to complete the challenge!

Path 1

Firebase AI Logic: Smart Server-Side Prompting

Mission: Build a smart server-side application using Firebase AI Logic that safely handles LLM interactions in a secure backend environment.
🔗 View the Official Codelab Reference

Starter Prompt

"Set up a new Node.js backend using Firebase Functions and the Firebase AI Logic SDK. I want to build a smart 'Sentiment & Summarization' API endpoint. The endpoint should take a block of text from a user, securely call the Gemini API on the backend using my Firebase setup, and return a JSON object containing a 1-sentence summary and a sentiment score (Positive/Neutral/Negative)."

Prompt-Steering Goals

  • Goal 1: The Core Logic. Add error handling to ensure the endpoint gracefully handles empty inputs or API timeouts.
  • Goal 2: Structured Output. Prompt the AI to enforce strict JSON schemas on the Gemini output so the frontend always receives the exact same data structure.
  • Goal 3: Authentication Security. Prompt the AI to secure the endpoint using Firebase App Check or Auth so only logged-in users can trigger the AI logic.
Path 2

Cloud Run: Launch Your Portfolio Website

Mission: Build and deploy a modern, responsive personal portfolio website hosted seamlessly on Google Cloud Run.
🔗 View the Official Codelab Reference

Starter Prompt

"Create a modern, responsive personal portfolio website using HTML, CSS, and vanilla JavaScript. Include a hero section with my name and a generic tagline, an 'About Me' section, a 'Projects' grid, and a 'Contact' footer. Use a clean, tech-focused design with Google fonts. Make sure it is fully contained and ready to be deployed as a containerized app on Google Cloud Run."

Prompt-Steering Goals

  • Goal 1: Interactive Elements. Ask the AI to add a dark-mode toggle switch that persists in local storage.
  • Goal 2: Dynamic Project Filtering. Prompt the AI to add a category filter (e.g., 'Web', 'Mobile', 'AI') above the projects grid that animates the filtering.
  • Goal 3: Containerization. Ask the AI to generate a complete Dockerfile and cloudbuild.yaml so the app is ready for Cloud Run deployment.
Path 3

Cloud Run: Web-Based Retro Video Game

Mission: Code a fully playable 2D retro web game directly in the browser and containerize it for Cloud Run.
🔗 View the Official Codelab Reference

Starter Prompt

"Write a complete, playable 2D browser game in a single HTML file using an HTML5 Canvas and JavaScript. Make it a space shooter where the player controls a ship at the bottom, shoots lasers upwards, and destroys falling asteroids. Include a score counter, game over state, and simple restart button. Ensure the code is clean and well-commented."

Prompt-Steering Goals

  • Goal 1: Power-ups. Prompt the AI to add a rare 'shield' power-up that drops occasionally and protects the player from one hit.
  • Goal 2: Escalating Difficulty. Ask the AI to increase the speed and spawn rate of the asteroids as the player's score increases.
  • Goal 3: High Score Storage. Prompt the AI to save the player's all-time highest score using browser LocalStorage so it persists across refreshes.

🚢 Publish Your Creation

When you're ready to share your work with the world, it's time to deploy!

  • For Firebase (Path 1): Use the Firebase CLI to run firebase deploy --only functions.
  • For Cloud Run (Paths 2 & 3): Use the Google Cloud console or CLI to build your container and deploy it to Cloud Run.

(If you are using a personal Google account, you can typically leverage the free tier for Cloud Run and Firebase Spark plans—no credit card required for standard limits!)
